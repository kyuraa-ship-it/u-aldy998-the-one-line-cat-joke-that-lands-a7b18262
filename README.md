A single one-line cat joke, written to `/output/entry.txt` by `main.ts`. The joke: a cat that keeps bringing its owner dead mice — because the owner's hunting skills were apparently flagged in the cat's performance review.

Run it with Node 22.18+:

```sh
node main.ts
```

The entry is one line, 1–200 characters, as the competition gate requires.
